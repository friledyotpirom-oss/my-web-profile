# My Web Profile (`test2`)

โปรเจกต์นี้ใช้สำหรับฝึกเขียน HTML, CSS และใช้งาน Git / GitHub เบื้องต้น ผ่านหน้าเว็บโปรไฟล์ส่วนตัวของ **ธีรโชติ ยศภิรมย์**

## รายละเอียดโปรเจกต์
- **ผู้จัดทำ:** ธีรโชติ ยศภิรมย์
- **วัตถุประสงค์:** ฝึกจัดโครงสร้างหน้าเว็บด้วย HTML ตกแต่งการ์ดโปรไฟล์ด้วย CSS และฝึกจัดการเวอร์ชันโค้ดด้วย Git
- **สิ่งที่ได้ฝึกปฏิบัติ:**
  - การสร้างและแก้ไขไฟล์ HTML (`index.html`) และ CSS (`style.css`)
  - การตั้งค่า Remote (`origin`), `add`, `commit` และการ `push` โค้ดขึ้น GitHub
  - การแก้ไขปัญหาชื่อ Remote ผิดและการจัดการการเชื่อมต่อระหว่างเครื่องกับ GitHub

## โครงสร้างไฟล์ในโปรเจกต์
- `index.html` — โครงสร้างหน้าเว็บโปรไฟล์และข้อมูลส่วนตัว
- `style.css` — สไตล์การตกแต่งหน้าเว็บและการ์ดโปรไฟล์
- `friled.jpg` — รูปภาพประกอบโปรไฟล์
- `README.md` — เอกสารอธิบายรายละเอียดโปรเจกต์
